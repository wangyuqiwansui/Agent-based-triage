Horizontal Modes / 横轴模式

Chain / 链式chain

Sequential / 顺序

Ordered steps where each output feeds the next. / 有序步骤，前一步输出进入下一步。

Routing / 路由routing

Conditional branching / 条件分支

Classify work and dispatch it to a path, tool, role, Skill, or owner. / 分类工作并分派到路径、工具、角色、Skill 或负责人。

Parallel / 并行parallel

Fan-out / 扇出

Run independent streams concurrently before merge or comparison. / 独立工作流并发运行后再合并或比较。

Orchestration / 编排orchestration

Controller-mediated / 控制器协调

Use a controller to coordinate tools, agents, state, dependencies, and handoffs. / 使用控制器协调工具、Agent、状态、依赖和交接。

Loop / 循环loop

Iterative / 迭代

Repeat observe-act-check until an explicit exit condition is met. / 重复观察、行动、检查，直到满足明确退出条件。

Hierarchy / 层级hierarchy

Recursive or layered / 递归或分层

Decompose work across strategy, plan, task, subtask, review, or authority levels. / 按战略、计划、任务、子任务、评审或权限层级拆解工作。
